# 黄骅港项目总包合同修订意见对照稿

## 一、修订结论

确认本轮修订不推翻现有总包合同主结构。  
确认本轮修订保留以下原合同基础口径：

1. 合同名称和总包承接关系保留。
2. 市场调节价机制保留。
3. 煤炭运输“新华冶金、码头运价双比对”口径保留。
4. 铝矿运输“兴安化工、奥凯达、信发铝业运价三比对”口径保留。
5. “所有价格调动，甲方以邮箱方式告知乙方”口径保留。
6. “各项运输任务以合同约定邮箱邮件为准，包括但不限于盖章运单、计划表、系统数据”口径保留。

本轮修订重点不在重写定价体系，而在收缩乙方责任边界、降低价格未锁定条件下的刚性履约责任和失衡违约责任。
结合当前商务判断，货主方不会采纳补价机制、最低运价保障机制和调价协商机制补强。因此，本稿不再将争取价格条款优化作为修订目标。

## 二、总体修订原则

1. 保留价格机制，不再将补价、保底、调价协商机制作为修订目标。
2. 保留邮件和清单作为附件及执行依据。
3. 收缩“无条件运力保障、无条件完成运输任务、无条件承担违约”的表述。
4. 增加“价格未锁定时责任不刚性、执行可调整”的边界条款。
5. 增加“可控事项与不可控事项区分处理”的规则。

## 四、建议删除或替换的高风险表述

### （一）建议删除

1. “乙方必须无条件确保运力供应”
2. “按时完成运输任务，否则即构成违约”
3. “乙方承担一切运输结果责任”
4. “乙方承担全部损失或全部赔偿责任”

### （二）建议替换

1. 将“无条件确保运力供应”替换为“在甲方按约下达任务并具备相应执行条件前提下，乙方合理组织运力保障”
2. 将“按时完成运输任务，否则构成违约”替换为“乙方在可执行条件下按约组织运输服务，对自身可归责的履约瑕疵承担责任”
3. 将“承担全部损失”替换为“对自身明确违约造成的直接损失承担责任”

## 五、建议新增条款

### （一）责任边界条款

明确乙方仅对业务组织、过程管理、履约协调和自身可控事项承担责任，不承接无边界价格风险。

### （二）执行调整条款

明确在市场价格明显失衡、执行条件重大变化、回款异常等情况下，乙方有权提出缩量执行、暂停履行、阶段复核和重新协商。

### （三）不可控事项条款

明确市场运价波动、场站变化、政策变化、货量变化、返程条件变化等事项不直接认定为乙方违约。

### （四）损失边界条款

明确不承担间接损失、机会损失、预期利益损失和无限额赔偿责任。

## 六、附件修订意见

1. 保留现合同“邮箱邮件 + 盖章运输清单 + 运单 + 计划表 + 系统数据”的附件与执行依据体系。
2. 不建议另起脱离原合同逻辑的“运价确认单、异常确认单、重谈确认单”等独立附件体系。
3. 如确需补充附件，建议仅补以下三类：
   1. 《盖章运输清单》
   2. 《合同约定邮箱信息及邮件确认规则》
   3. 《运输服务费结算确认单》

## 七、修订优先级

1. 第一优先：运力保障、违约责任、损失赔偿、解除退出。
2. 第二优先：合同定位、结算依据、不可控事项。
3. 第三优先：附件整理和邮件规则固化。
