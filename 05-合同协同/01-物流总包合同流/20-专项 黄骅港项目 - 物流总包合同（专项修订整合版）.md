# 运输服务合同

合同编号：________

甲方（托运人）：沧州黄骅港供应链管理集团有限公司  
乙方（承运人）：汉江数智科技发展（襄阳）有限公司

经甲、乙双方友好协商，在互利共赢原则基础上，就黄骅港项目运输服务合作事宜达成一致。为保证运输任务有序推进，明确双方责任边界、结算依据和履约规则，依据《中华人民共和国民法典》及有关法律法规，订立本合同，以便双方共同遵守。

## 一、合作内容

### 1.1 服务范围

甲方委托乙方参与黄骅港区域至山西灵石、孝义、介休等地区大宗散货运输服务。货物以铝矾土、煤炭为主，具体货物类别、运输线路、运输批次、作业要求和执行安排，以甲方按合同约定邮箱发送的邮件、盖章运输清单、运单、计划表、系统数据及其他书面资料为准。

### 1.2 年度基础运量

本合同项下，甲方与乙方确认三年合作期内以 `600` 万吨运输规模作为合作基础目标。  
前述基础目标用于明确合作规模和业务组织安排，不当然构成在市场价格未锁定、最低运价未保障、调价协商机制未建立条件下，乙方对固定规模、固定收益和固定结果的绝对承诺。  
实际委托运输量以甲方按合同约定邮箱下达并经执行确认的各项运输任务为准。

### 1.3 运力组织

乙方应根据甲方按约发送的运输任务，结合实际执行条件，及时调配符合要求的车辆和人员，安全、准确地将货物运抵指定地点。  
在甲方已按约发送运输任务、价格已按约告知且现场作业条件具备的前提下，乙方应合理组织运力保障。  
因市场价格明显失衡、场站条件变化、货量变化、返程组织变化、回款异常及其他非乙方单方可控原因影响执行的，乙方有权按本合同约定提出调整执行安排，不直接视为乙方违约。

### 1.4 运量确认与任务依据

甲方保障合同约定的合作运输规模。实际委托的各项运输任务以合同约定邮箱邮件为准，包括但不限于盖章的运输清单、运单、计划表、系统数据及其他书面资料。  
前述资料同时作为双方确认运输任务、组织执行、对账结算和争议举证的依据。

### 1.5 合同期间

本合同合作期间为 `3` 年，自双方法定代表人或授权代表签字并加盖公章之日起生效。

## 二、运输费用及结算支付

### 2.1 定价原则

本合同项下运输服务费实行市场调节价。运输价格以市场价格为主，具体执行如下：

1. 孝义地区至黄骅港区域煤炭运输，以新华冶金、码头运价双比对方式作为定价依据。
2. 黄骅港区域至孝义地区铝矿运输，以兴安化工、奥凯达、信发铝业运价三比对方式作为定价依据。
3. 其他货物运输价格参照前述比对原则执行。
4. 所有价格调动，由甲方以合同约定邮箱方式告知乙方。

前述定价机制为本合同现行基础定价口径。  
在补价机制、最低运价保障机制和调价协商机制未建立前，乙方不因前述市场调节价安排当然承接无边界价格风险，不对固定利润覆盖、固定结果交付和无限收益缺口承担兜底责任。

### 2.2 结算依据

双方运输服务费结算以以下资料作为依据：

1. 合同约定邮箱邮件。
2. 盖章运输清单。
3. 运单、计划表、系统数据。
4. 双方确认的运输服务费结算确认资料。

如前述资料存在不一致，双方应先行核对并补正后再行结算。

### 2.3 专项价格判断口径

本合同项下涉及承运层自担波动、执行边界触发、停运重谈和恢复执行时，执行以下专项判断口径：

1. **实际到手结算吨价**：指甲方当期最终确认结算收入，扣除折让、扣罚、异常扣款及其他已确认减项后的净收入，再除以当期实际完成运输吨数形成的实际结算单价。
2. **完全成本总额**：指乙方当期实际执行中已经形成或应当形成的全部运输经营成本总额，包括车辆租赁相关成本或车辆占用成本、能源成本、司机人工成本、维保成本、管理成本、税费、运费账期资金成本和车租账期资金成本。
3. **执行边界线**：指完全成本总额除以当期实际完成运输吨数形成的单位吨成本价格。
4. **承运调节线**：指承运分包结算总价除以当期实际完成运输吨数形成的单位吨价格。
5. **正式判断口径**：乙方可基于承运调节线判断执行层波动归属，但项目是否进入执行边界触发区，仅以实际到手结算吨价与项目总执行边界线的对比结果为准。

### 2.4 对账与付款

双方按月或按双方另行确认的周期进行对账结算。  
甲方应按双方确认的结算结果向乙方支付运输服务费。  
具体结算周期、对账确认方式、付款期限和付款信息，以附件三《运输服务费结算确认单》及双方书面确认资料为准。  
涉及专项运费调节判断时，双方应同步形成附件四《完全成本确认表》和附件五《实际到手结算价与运费调节测算表》。

甲方未按约完成价格告知、运输任务确认、对账确认或付款安排的，乙方有权暂停对应批次新增执行安排，并书面通知甲方。

### 2.5 发票

乙方按双方确认的结算金额向甲方开具合法有效发票。  
甲方应按合同约定及结算确认结果完成付款。

## 三、双方权利和义务

### 3.1 甲方权利和义务

1. 有权根据业务需要向乙方下达运输任务。
2. 有权依据市场调节价机制按合同约定邮箱向乙方发送价格调整通知。
3. 应及时、全面、真实地向乙方提供货源信息、线路信息、装卸要求、时效要求及其他履约基础信息。
4. 应按合同约定邮箱方式发送运输任务、价格调动信息及其他执行通知。
5. 应配合乙方完成运输任务确认、对账确认和付款安排。
6. 对邮件、盖章运输清单、运单、计划表、系统数据等书面资料的真实性、完整性负责。

### 3.2 乙方权利和义务

1. 有权承接甲方委托的运输服务，并组织相应运力资源和执行安排。
2. 有权依据甲方按约发送的邮件、盖章运输清单及相关资料组织运输执行。
3. 有权在市场价格明显失衡、执行条件重大变化、回款异常或其他重大不利变化情形下，提出缩量执行、暂停履行、阶段复核和重新协商。
4. 有权在实际到手结算吨价进入承运层自担波动区或执行边界触发区时，提出执行层波动吸收、暂停新增投放、停新增保在途、停运重谈和恢复执行复核。
5. 应在合理可执行条件下，组织车辆和人员完成运输任务。
6. 应做好运输过程中的组织协调、信息反馈、单据回传和对账配合。
7. 仅对业务组织、过程管理、履约协调及自身可控事项承担责任，不承接无边界价格风险和与收益明显不匹配的刚性结果责任。

## 四、责任边界与违约责任

### 4.1 责任边界

乙方在本合同项下承担的责任，以业务组织责任、过程管理责任、已明确约定且具备履行条件的可控履约责任为限。  
乙方不承担以下责任：

1. 市场运价波动导致的无限收益缺口责任。
2. 未设置最低运价保障条件下的结果兜底责任。
3. 未建立调价协商机制前的长期刚性履约责任。
4. 政策变化、场站变化、货量变化、返程条件变化、回款异常等不可归责于乙方的风险责任。

### 4.2 不可控事项处理

因市场价格波动、政策变化、场站条件变化、货源波动、返程条件变化、交通管制、恶劣天气及其他非乙方单方可控事项导致运输条件发生重大变化的，不直接认定为乙方违约。  
前述事项发生后，双方应及时协商采取缩量执行、调整安排、阶段复核、重新协商等措施。

### 4.3 双层运费调节处理

双方同意按“周监测、月确认”节奏对项目执行价格进行专项复核，并按以下规则执行：

1. 当实际到手结算吨价高于承运调节线时，项目处于正常执行区，可继续按计划执行。
2. 当实际到手结算吨价低于或等于承运调节线，但仍高于项目总执行边界线时，由承运物流企业进入执行层自担波动区，项目继续执行，不单独触发项目停做。
3. 当实际到手结算吨价低于或等于项目总执行边界线时，项目进入执行边界触发区。乙方有权执行“停新增、保在途”，停止新增接单、停止新增投放、停止新批次上车和起租，并立即向甲方发出价格重谈通知。
4. 当项目连续一个完整确认周期处于执行边界触发区时，乙方有权启动停运重谈，并就继续执行、缩量保留或停运退出与甲方协商形成书面结论。
5. 执行边界触发后的存量任务处理，原则上以“已在途、已承诺任务优先收尾，未启动批次不再新增”为准。
6. 恢复执行须同时满足以下条件：
   1. 实际到手结算吨价重新高于项目总执行边界线；
   2. 连续一个确认周期稳定；
   3. 回款周期未继续恶化。
7. 上述承运层自担波动、执行边界触发、停运重谈和恢复执行结论，均以双方书面确认资料、附件四和附件五以及合同约定邮箱通知为依据。

### 4.4 违约责任

一方违反本合同明确约定，且给对方造成直接损失的，应依法承担相应责任。  
违约责任应与违约行为、可归责程度和已确认收益基础相匹配。

乙方对自身明确违约造成的直接损失承担责任，但不承担以下责任：

1. 无限额赔偿责任。
2. 间接损失赔偿责任。
3. 机会损失、预期利益损失赔偿责任。
4. 与收益明显不匹配的高额违约责任。

### 4.5 执行调整与退出

出现以下情形之一时，乙方有权提出缩量执行、暂停履行、部分解除或协商解除：

1. 实际到手结算吨价低于或等于项目总执行边界线且持续无法改善。
2. 甲方长期未完成对账确认或付款。
3. 场站、线路、配载或作业条件发生重大不利变化。
4. 其他导致项目继续执行明显失衡的情形。

合同解除前已经实际完成的运输服务，双方仍应依据已确认事实完成对账和结算。

## 五、争议解决

本合同履行过程中发生争议的，双方应先协商解决；协商不成的，提交【待填写】仲裁委员会仲裁，或向【待填写】有管辖权的人民法院提起诉讼。
