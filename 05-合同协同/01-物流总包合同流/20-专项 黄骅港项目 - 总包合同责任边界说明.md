# 黄骅港项目总包合同责任边界说明

## 一、说明结论

确认在货主侧未提供补价机制、最低运价保障机制和调价机制的前提下，合同物流企业不宜在总包合同中承接无边界价格风险，不宜承接与收益能力不匹配的刚性结果责任。  
黄骅港项目当前总包合同应定位为业务入口合同和框架性承接合同，责任安排应以可控履约责任为主，以程序性协同义务为辅，不将不可控价格波动风险写入合同物流企业承责范围。

## 二、适用前提

本说明适用于以下情形：

1. 货主总包合同未锁定明确运价。
2. 货主总包合同未提供最低运价保障。
3. 货主总包合同未设置明确调价机制。
4. 市场运价、配载条件、场站条件和执行成本存在明显波动。

## 三、责任边界总原则

执行“未锁价格，不锁责任；未保底线，不承接刚性结果；未设调价，不接受长期僵化履约”的责任边界原则。

## 四、专项口径固化

### （一）定价逻辑处理口径

固化“保留现有定价逻辑、不再争取价格条款调整”的专项口径。

1. 保留货主侧现有市场调节价机制。
2. 保留煤炭运输“双比对”和铝矿运输“三比对”定价口径。
3. 保留“所有价格调动由甲方以邮箱方式告知乙方”的现有通知方式。
4. 不再将补价机制、最低运价保障机制和调价协商机制作为本轮总包合同修订目标。
5. 不再以修改货主定价逻辑作为项目可执行性的前置条件。

### （二）专项整改转向口径

执行“定价逻辑不重写、责任边界要收缩、执行调整权要保留、过程留痕要补强”的整改口径。

1. 将总包合同定位为业务入口合同和框架性承接合同。
2. 将整改重点从争取价格条款转向控制责任边界和执行风险。
3. 将价格波动风险的内部承接和消化，转入专项模型、分包合同和清分规则处理中。
4. 将总包合同调整重点锁定为责任边界、违约边界、执行调整和程序留痕四类事项。

## 五、合同物流企业可承接责任

在总包合同中，合同物流企业可承接以下责任：

### （一）业务组织责任

1. 承接项目业务入口。
2. 组织运输资源对接和执行安排。
3. 协调下游承运体系和现场协同接口。

### （二）过程管理责任

1. 配合运输任务下达、回传和在途跟踪。
2. 配合对账、回款、单据归集和过程留痕。
3. 配合异常信息反馈和执行调整沟通。

### （三）可控履约责任

1. 对自身可控范围内的组织失误、信息失真、管理疏漏承担责任。
2. 对合同已明确约定且具备履行条件的事项承担对应责任。
3. 对因自身直接违约造成的直接损失承担责任。

## 六、合同物流企业不宜承接责任

在总包合同中，合同物流企业不宜承接以下责任：

### （一）不宜承接无边界价格风险

1. 不承接市场运价波动导致的无限收益缺口责任。
2. 不承接成本上涨、场站变化、返程配载变化等不可控因素形成的结果风险。
3. 不承接货主未提供价格保护条件下的当然保价义务。

### （二）不宜承接刚性结果责任

1. 不承接在收入未锁定前提下的固定利润覆盖责任。
2. 不承接固定规模、固定趟次、固定收益率等绝对结果承诺。
3. 不承接超出合同物流企业控制能力的整体经营兜底责任。

### （三）不宜承接无限延伸责任

1. 不承接无限额赔偿责任。
2. 不承接间接损失、机会损失、预期收益损失等无限外扩赔偿责任。
3. 不承接未在合同中明确传导、未形成收益匹配基础的连带责任或替代责任。

## 七、围绕现有市场调节价机制重构的责任边界和执行调整机制

### （一）责任边界重构方向

围绕现有市场调节价机制，重构总包合同责任边界。

1. 将乙方责任从“结果兜底”收缩为“可控履约”。
2. 将乙方责任从“无条件持续执行”收缩为“在具备执行条件下组织执行”。
3. 将市场运价波动、返程配载变化、场站条件变化、政策变化、货量波动等事项明确划入非单方可控事项。
4. 将货主侧单方价格通知与乙方执行安排之间增加复核、预警和调整接口。
5. 将违约责任限定在一方明确违约且造成对方直接损失的范围内。

### （二）执行调整机制重构方向

围绕现有价格通知和任务下达机制，补程序性执行调整机制。

1. 增加价格复核环节。
说明：甲方发出价格调整邮件后，乙方有权结合当前运价、执行成本、返程条件和场站条件开展复核。
2. 增加亏损预警环节。
说明：当价格条件不足以支撑正常执行区时，乙方有权发出书面预警并提出调整建议。
3. 增加缩量执行环节。
说明：当局部线路、局部批次或阶段性任务进入承压执行区时，乙方有权申请缩量组织执行。
4. 增加暂停投放环节。
说明：当新增投放将导致明显失衡时，乙方有权暂停新增车辆和新增任务投放。
5. 增加停运重谈环节。
说明：当价格持续失衡、回款异常或执行条件重大变化时，乙方有权提出阶段停运和重谈。
6. 增加恢复执行环节。
说明：当价格、回款和执行条件恢复到正常执行区后，再按复核结论恢复执行。

### （三）建议写入合同或配套文件的程序性表述

1. 明确价格调整后，乙方享有复核权和书面反馈权。
2. 明确进入异常区间后，乙方享有缩量、暂停、重谈和恢复执行的程序性权利。
3. 明确上述调整不当然构成乙方违约。
4. 明确执行调整应以合同约定邮箱邮件、运输清单、计划表和回传记录为依据留痕。

## 八、建议固化的合同表达方向

### （一）合同属性表述

建议将总包合同表述为业务入口合同、框架性承接合同或阶段性合作合同，不将其写成对价格稳定性和经营结果作出完整承诺的终局承诺文件。

### （二）责任归属表述

建议将合同物流企业责任限定在业务组织、过程管理、履约协调、对账配合、信息反馈等可控范围内。

### （三）风险排除表述

建议明确市场价格波动、政策变化、场站变化、货源波动、返程条件变化等非合同物流企业单方可控事项，不直接认定为合同物流企业违约。

### （四）执行调整表述

建议明确在持续亏损、价格失衡、成本异常上升、回款异常等情形下，合同物流企业有权提出缩量执行、暂停投放、阶段复核和重新协商。

## 九、建议保留的程序性权利

1. 保留价格复核权。
2. 保留亏损预警权。
3. 保留缩量执行权。
4. 保留暂停投放权。
5. 保留重谈和恢复执行的程序性权利。

## 十、审阅与谈判口径

在货主侧无法提供价格约束条件时，总包合同的审阅重点应由“争取补价和保底”转向“收缩责任边界、保留调整权、控制违约责任、强化程序留痕”。

建议统一使用以下口径：

“在未形成稳定运价锚点、最低运价保障和调价机制前，合同物流企业仅在可控履约范围内承担业务组织与过程管理责任，不承接无边界价格风险，不承担与收益不匹配的刚性结果责任，并保留缩量、暂停和重谈的程序性权利。”
