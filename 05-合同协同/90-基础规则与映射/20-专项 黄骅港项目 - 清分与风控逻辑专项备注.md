# 黄骅港项目清分与风控逻辑专项备注

## 一、备注目的

明确黄骅港项目在货主运价未锁定条件下，合同物流企业、承运物流企业之间的专项清分顺序、风险承担边界、运费调节判断口径及附件使用原则。

本备注用于统一项目方案、财务模型、总包合同、分包合同、附件及上会材料中的专项表达。

## 二、适用范围

适用于黄骅港项目当前“总包承接 + 合同物流企业组织执行 + 承运物流企业承担执行层波动”的专项业务结构。

本备注不替代结算单、发票、对账单或财务入账凭证，仅作为专项合同安排、测算判断及风控执行的统一口径说明。

## 三、专项清分顺序

黄骅港项目专项清分按以下顺序执行：

1. 优先覆盖合同物流企业刚性支出。
2. 再支付承运司机费用。
3. 再支付承运管理费用。
4. 最后确认承运毛利。

前述清分顺序用于判断专项项目在不同运价条件下的可执行性、承运侧承压区间及合同物流企业执行边界。

## 四、合同物流企业刚性支出口径

合同物流企业刚性支出覆盖要求，按当期实际口径确认，主要包括：

1. 运费垫资利息。
2. 车租垫资利息。
3. 车辆租金，包括牵引车和挂车。
4. 保险费用。
5. 能源费用。
6. 维保费用。
7. 货主支付物流费用对应税费。
8. 其他经双方书面确认、由合同物流企业实际承担且不可向承运侧转嫁的必要支出。

其中，货主支付物流费用对应税费属于变量成本，原则上按货主支付物流费用的适用税率联动测算；在当前专项测算中，暂按 `9%` 口径作为基线。

## 五、专项风控逻辑

黄骅港项目专项风控按“先保合同物流企业刚性支出、再由承运侧吸收执行层波动”的原则执行。

具体判断如下：

1. 当货主支付物流费用足以覆盖合同物流企业刚性支出、承运司机费用、承运管理费用及承运毛利时，项目处于正常执行区。
2. 当货主支付物流费用足以覆盖合同物流企业刚性支出、承运司机费用及承运管理费用，但不足以覆盖承运毛利时，承运毛利压缩或归零，由承运物流企业承担。
3. 当货主支付物流费用足以覆盖合同物流企业刚性支出，但不足以覆盖承运司机费用、承运管理费用及承运毛利时，承运侧执行层缺口由承运物流企业承担，项目不当然停止执行。
4. 当货主支付物流费用不足以覆盖合同物流企业刚性支出时，触发合同物流企业执行边界预警，并启动暂停新增、保在途、价格重谈等专项动作。

## 六、专项边界定义

### （一）合同物流企业执行边界线

指合同物流企业刚性支出覆盖要求合计，除以当期实际完成运输吨数形成的单位运价边界。

当实际到手运价低于该边界线时，认定合同物流企业进入执行边界触发区。

### （二）承运侧承压边界

指合同物流企业刚性支出覆盖要求、承运司机费用及承运管理费用之和，除以当期实际完成运输吨数形成的单位运价边界。

当实际到手运价低于该边界但仍高于合同物流企业执行边界线时，认定承运物流企业进入执行层承压区，由承运物流企业承担执行层缺口。

## 七、预测值与实际值使用原则

黄骅港项目当前模型中的部分数据属于预测性基线数据。为避免预测值与实际值偏差导致合同履行争议，执行以下原则：

1. 正文锁定规则，不锁定预测数字。
2. 附件锁定签约基线参数，不直接替代月度实际值。
3. 月度清分与运费调节测算确认单，作为当期专项判断和动作执行依据。
4. 关键变量较基线明显偏离时，启动专项复核并更新附件或补充协议。

## 八、附件使用原则

专项合同及附件应至少形成以下闭环：

1. 《完全成本确认表》用于确认当期合同物流企业刚性支出口径。
2. 《实际到手结算价与运费调节测算表》用于确认当期实际运价、边界线及动作结论。
3. 月度确认单、对账单、通知邮件及专项审批单据，作为专项执行和责任留痕依据。

## 九、引用建议

建议在下列文件中引用本备注：

1. 总包合同正文有关运费调节、执行边界和停运重谈条款。
2. 分包合同有关承运侧承压边界、执行层缺口承担和配合义务条款。
3. 财务模型及测算表有关清分顺序、边界口径和动作结论说明。
4. 上会材料有关专项模式、收益归属和风险承担说明。
