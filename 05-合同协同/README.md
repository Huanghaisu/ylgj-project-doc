# 合同协同目录说明

## 一、建设原则

本目录用于沉淀项目合同体系，当前阶段以平台公司优先为原则，在统一公共定义的基础上，逐步扩展合同物流企业相关协议体系。

合同体系应服务以下目标：

- 固化各参与方责任边界
- 固化交付与执行标准
- 固化结算与清分路径
- 固化风控要求与违约责任
- 保证合同文本与项目方案、财务模型口径一致

## 二、建议目录骨架

### 1. `01-公共定义与清单`

建议承接：

- 合同体系总览
- 角色定义与主体映射表
- 合同清单与签署关系表
- 条款口径统一说明

用途：
用于统一角色名称、主体关系、签署路径及后续合同的通用术语。

### 2. `02-平台公司协议`

建议承接：

- 项目合作框架协议
- 平台服务协议
- 运力托管/调度管理协议
- 数据采集与真实性确认文件

用途：
用于固化平台公司作为运力管家的服务内容、职责边界、收费依据及数据管理要求。

### 3. `03-车辆与资产协议`

建议承接：

- 车辆租赁协议
- 持车服务协议
- 融资租赁相关配套文件
- 车辆交付与验收确认单

用途：
用于固化持车主体、租赁关系、交付标准及车辆相关责任边界。

### 4. `04-运输与执行协议`

建议承接：

- 运输服务协议
- 委托执行协议
- 承运管理协议
- 安全生产责任书

用途：
用于固化运输履约责任、现场执行边界及安全生产责任。

### 5. `05-结算与清分协议`

建议承接：

- 资金清分与结算协议
- 受控账户管理协议
- 账期收益安排说明
- 对账确认单模板

用途：
用于固化运费流入、专户控制、清分顺序、账期收益和对账规则。

### 6. `06-合同物流企业扩展`

建议承接：

- 总包与转包管理协议
- 账期收益安排协议
- 合同真实性穿透文件

用途：
用于第二阶段补齐合同物流企业的专属权责与收益安排。

## 三、与项目方案的映射关系

- `项目背景/项目定位`
  对应框架协议中的合作目标、合作范围、项目定义。
- `核心参与方角色定位`
  对应公共定义文件、主体映射表、角色责任条款。
- `核心业务流程/操作环节`
  对应运输执行协议、车辆交付文件、平台服务协议。
- `资金结算与清分`
  对应结算与清分协议、受控账户管理协议、对账文件。
- `风控安排`
  对应数据真实性文件、安全责任书、违约责任条款。

## 四、与财务模型的映射关系

- `1-基础参数`
  对应合同中的运价、里程、车队规模、租赁方式、账期等关键参数。
- `2-单车成本测算`
  对应车辆租赁、保险、能源、维保、司机、管理等费用条款。
- `3.5-资金清分`
  对应信息服务费、车辆租赁费、账期收益、清分顺序、支付路径。
- `4-相关方收益分配`
  对应各协议中的收入归属、费用承担与结算责任。

## 五、编制要求

- 不得先写正文、后补角色定义。
- 不得出现与财务模型不一致的费率、账期与支付路径。
- 不得混用平台公司、合同物流企业、持车服务公司等主体名称。
