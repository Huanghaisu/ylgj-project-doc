# 合同协同目录说明

本目录用于沉淀合同体系文件，统一承接条款口径、附件体系、清分逻辑及阶段性合同梳理材料。

## 当前基线

- `00-基线 合同条款 - 资金清分逻辑映射.md`
  当前合同条款与资金清分之间的主口径文件。

- `10-模板 三方合同 - 附件体系清单.md`
- `06-合同物流企业扩展/10-模板 合同物流企业 - 协议骨架.md`

## 子目录说明

- `01-公共定义与清单`
  统一角色、主体映射和合同清单。
- `02-平台公司协议`
  承接平台公司相关正式协议。
- `03-车辆与资产协议`
  承接车辆、持车和交付验收相关协议。
- `04-运输与执行协议`
  承接运输履约、委托执行与安全责任协议。
- `05-结算与清分协议`
  承接清分、账期、专户和对账规则协议。
- `06-合同物流企业扩展`
  承接合同物流企业专属协议与扩展文件。

## 使用规则

1. 当前正式条款口径优先引用 `00-基线` 文件。
2. 协议骨架和附件体系作为模板使用，不直接替代正式合同。
3. 历史外部合同文本统一放入 `99-归档`，不再与现行口径文件混排。
