# 合同协同目录说明

## 一、当前主轴

本目录当前统一按“五流合同主轴”组织：

1. 货主 -> 合同物流企业：物流总包合同流
2. 合同物流企业 -> 承运物流企业：物流分包合同流
3. 持车平台 -> 平台公司：资产委托合同流
4. 平台公司 -> 合同物流企业：车辆租赁合同流
5. 持车平台 + 平台公司 + 合同物流企业：特殊三方合同流

统一命名口径：

- 货主
- 合同物流企业
- 承运物流企业
- 持车平台
- 平台公司

## 三、当前整理原则

- 不删除任何已有文件
- 不覆盖已有文件
- 可明确归属的历史文件，优先归入适合的合同流目录
- 暂不继续拆分的旧结构，统一保留在 `99-归档`
