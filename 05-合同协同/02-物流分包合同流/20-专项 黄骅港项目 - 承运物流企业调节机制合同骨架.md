# 黄骅港项目承运物流企业调节机制合同骨架

## 一、合同定位

用于承接黄骅港项目专项模型下，合同物流企业向承运物流企业输出的专项分包合同逻辑。

本合同骨架重点解决价格波动收益与风险调节、执行阈值判断、缩量停运机制和专项清分接口问题。

## 二、合同主体建议

1. 甲方：汉江数智科技发展(襄阳)有限公司。
2. 乙方：承运物流企业。

## 三、核心条款模块

### （一）项目范围

明确运输线路、货类、运量区间、执行周期、车辆组织要求和返程组织原则。

### （二）专项模型适用条款

明确本合同适用黄骅港项目专项模型，价格波动收益与风险按专项约定执行，不外推至其他项目。

### （三）价格机制条款

明确以下内容：

1. 市场运价确认口径。
2. 运价复核周期。
3. 价格波动判断依据。
4. 价格变化情况下的通知和确认程序。

### （四）固定成本与硬性费用条款

明确固定成本、硬性费用和必要执行支出的识别口径，并约定其在专项清分中的优先顺序。

### （五）承运物流企业调节职责条款

明确以下内容：

1. 乙方在可执行区间内承担执行层价格波动收益与风险调节职责。
2. 乙方在运价上行时可按约定享有弹性收益。
3. 乙方在运价正常波动时按约定吸收执行层波动。
4. 乙方在运价跌破阈值时配合启动缩量、暂停或重谈。

### （六）熔断机制条款

明确以下内容：

1. 熔断触发条件。
2. 熔断判断主体。
3. 熔断触发后的任务处理顺序。
4. 缩量执行、暂停执行和恢复执行条件。

### （七）对账与清分接口条款

明确以下内容：

1. 对账基础资料。
2. 回款确认后的专项清分顺序。
3. 固定成本和硬性费用优先安排原则。
4. 乙方弹性收益或波动吸收结果确认方式。

### （八）责任边界条款

明确以下内容：

1. 乙方承担执行层组织、运输执行和专项调节义务。
2. 乙方不承担甲方对外总包合同中未传导或未对应配置收益的额外义务。
3. 甲方不向乙方转嫁未形成专项约定的无限价格风险。

### （九）退出与恢复条款

明确以下内容：

1. 进入熔断区间后的缩量和暂停安排。
2. 恢复执行的复核条件。
3. 重大波动下的重谈程序。

## 四、附件建议

1. 运输计划附件。
2. 价格校验附件。
3. 固定成本和硬性费用确认附件。
4. 专项清分规则附件。
5. 熔断触发与恢复流程附件。
