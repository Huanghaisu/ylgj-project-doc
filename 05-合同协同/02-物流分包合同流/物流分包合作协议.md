甲、乙双方依据《中华人民共和国民法典》及道路货物运输相关法律法规，在平等、自愿、诚实信用原则基础上，就黄骅港项目运输业务分包、执行层价格波动调节、专项清分和恢复执行复核等事项，经协商一致，订立本协议。

## 第一条 合同定位

1. 本协议为黄骅港项目专项模型项下的分包执行协议。
2. 本协议用于明确甲方作为合同物流企业与乙方作为承运物流企业之间的业务分工、价格复核、专项清分、执行调整、恢复执行复核和责任边界。
3. 双方确认，乙方在本项目中统一定义为执行层价格波动收益与风险调节层。
4. 双方确认，本协议仅适用于黄骅港项目专项模型，不直接适用于其他项目。

## 第二条 定义

除上下文另有约定外，下列术语具有如下含义：

1. `分包业务`：指甲方将其承接的黄骅港项目运输任务，按照本协议约定交由乙方实际组织执行的运输业务。
2. `运输任务`：指甲方通过任务通知单、任务邮件、平台系统或其他书面形式向乙方下达的单次或批次运输安排。
3. `执行资料`：指运输任务通知、电子运单、过磅单、提卸货单、签收回单、轨迹数据、图片资料、对账资料及其他双方确认的履约留痕材料。
4. `价格校验`：指甲、乙双方根据市场运价、线路、趟次效率、固定成本、硬性费用及执行条件，对对应期间或批次任务是否处于正常执行区、承压执行区或执行边界触发区进行复核确认。
5. `固定成本与硬性费用`：指为维持本项目正常执行必须优先保障的刚性支出，具体口径以附件三《固定成本与硬性费用确认表》为准。
6. `专项清分`：指在确认执行量和可确认回款后，按照专项模型顺序对本期收益和支出进行确认的过程。
7. `正常执行区`：指价格条件足以覆盖固定成本、硬性费用，并可按约确认执行层收益的区间。
8. `承压执行区`：指价格条件足以覆盖合同物流企业刚性支出，但不足以完整覆盖执行层收益的区间。
9. `执行边界触发区`：指价格条件不足以覆盖合同物流企业刚性支出，项目不得按原节奏继续新增投放的区间。

## 第三条 分包范围与业务边界

1. 甲方将黄骅港区域至山西灵石、孝义、介休等地区煤炭、铝矾土等运输业务分包给乙方执行。
2. 具体线路、货类、批次、数量、班次、车辆安排和时效要求，以甲方下达的运输任务及其附件为准。
3. 甲方有权根据项目实际情况确定分包业务量，不承诺最低分包量。
4. 乙方作为独立承运主体，自行组织驾驶员、现场衔接、车辆调度和运输执行，并对自身执行过程承担责任。
5. 本协议项下分包安排，不免除甲方对外总包合同责任；但甲方仅可在本协议明确约定的责任范围内向乙方追责，不得转嫁未传导、未配置收益或不属于乙方控制范围的额外义务。

## 第四条 项目适用与专项口径

1. 双方确认，本项目执行遵循以下专项口径：
一是货主合同为业务入口文本；  
二是乙方为执行层价格波动收益与风险调节层；  
三是甲方不承接无限价格波动风险；  
四是专项清分顺序为“先保刚性、再清执行、最后确认弹性收益”。
2. 双方确认，本协议项下收益、风险和执行动作，均以黄骅港项目专项模型文件和本协议附件约定为准。

## 第五条 运输任务下达与承接

1. 甲方应通过任务通知单、任务邮件或双方确认的平台系统向乙方下达运输任务。
2. 运输任务应至少载明：
一是货类、线路、提货地点、卸货地点；  
二是计划数量、提货时间、送达时间；  
三是适用价格口径或对应价格确认编号；  
四是单据要求、回传要求、异常反馈路径；  
五是其他必要执行要求。
3. 乙方收到运输任务后，应在约定时限内明确是否承接。
4. 乙方逾期未反馈的，甲方有权视为乙方不承接该批次任务，并另行安排其他执行资源。
5. 乙方承接任务后，应按约组织执行；但在出现本协议约定的价格失衡、执行边界触发或重大条件变化时，乙方有权依法提出执行调整建议。

## 第六条 车辆、人员与系统接入要求

1. 乙方用于执行本协议项下任务的车辆，应为甲方指定或书面确认可用于本项目的车辆。
2. 未经甲方书面同意，乙方不得擅自使用未经确认的车辆执行本协议项下任务。
3. 乙方应确保驾驶员具备合法有效的驾驶资格及从业资格，并对驾驶员管理承担责任。
4. 乙方应确保车辆定位设备、T-Box 或其他监控设备正常运行，不得擅自拆除、关闭、屏蔽或篡改。
5. 乙方同意项目执行数据接入甲方指定的平台或系统，并接受必要的穿透式管理。

## 第七条 价格确认、复核与调节机制

1. 本协议项下价格不采用固定兜底价模式，实行“任务价格确认 + 执行前价格校验 + 专项清分确认”的机制。
2. 甲方下达运输任务前或下达运输任务时，应同步向乙方说明对应价格口径。
3. 对批量任务、连续任务或价格波动明显期间，双方应使用附件二《承运价格校验表》进行复核。
4. 经价格校验，项目处于正常执行区的，乙方按约承接执行，并在专项清分中确认弹性收益。
5. 经价格校验，项目处于承压执行区的，乙方应按照专项约定吸收执行层缺口，甲方有权要求乙方在约定范围内继续承压执行；但双方应同步加强监测、压缩非必要投放，并及时复核。
6. 经价格校验，项目进入执行边界触发区的，双方应启动执行边界触发判断和执行调整，不得继续按原节奏新增投放。
7. 乙方不承担未在本协议及附件中明确约定的无限价格波动风险。

## 第八条 固定成本、硬性费用与专项清分

1. 双方确认，本项目专项清分顺序为：
一是确认实际执行量和可确认回款金额；  
二是优先覆盖合同物流企业刚性支出；  
三是再支付承运司机费用；  
四是再支付承运管理费用；  
五是最后确认承运毛利；  
六是完成其他协同主体按约定的支持性结算安排。
2. 固定成本与硬性费用口径，以附件三《固定成本与硬性费用确认表》为准。
3. 每个结算周期结束后，双方应根据执行资料、价格校验结果和可确认回款情况，共同确认专项清分结果。
4. 专项清分结果应通过附件五《专项清分结果确认单》予以固定。
5. 未经双方确认，任何一方不得单方改变专项清分顺序和收益归属。

## 第九条 运单管理与单据回传

1. 双方确认，运输任务的接收、执行、完成确认应通过双方认可的平台系统、电子运单或书面任务通知完成。
2. 每票运输任务完成后，乙方应按约回传完整执行资料，包括但不限于：
一是提货地空车过磅单；  
二是提货地满载过磅单；  
三是提货单或提货凭证；  
四是卸货地满载过磅单；  
五是卸货地空车过磅单；  
六是卸货单或签收回单；  
七是车辆外观或到场照片；  
八是双方约定的其他资料。
3. 乙方应保证回传资料真实、完整、有效。
4. 乙方未按约回传资料、资料缺失或存在明显瑕疵的，甲方有权暂缓对对应任务进行结算确认，直至资料补齐。
5. 乙方回传虚假资料、伪造资料、篡改数据的，甲方有权拒付对应任务运费，并追究违约责任。

## 第十条 结算周期、对账与付款

1. 双方原则上以自然月为结算周期。
2. 每月固定时间前，乙方应提交当期执行汇总和对账资料，甲方应组织复核。
3. 对账依据包括：
一是运输任务通知；  
二是电子运单状态；  
三是乙方回传的执行资料；  
四是价格校验结果；  
五是专项清分结果确认单。
4. 双方完成对账并确认后，形成附件四《月度运输任务执行计划及对账结算单》或其他结算确认文件。
5. 甲方应在双方确认应付款项、收到乙方合法有效发票并具备付款条件后，于约定期限内向乙方支付对应款项。
6. 如因上游回款未确认、专项清分结果未确认或乙方未完成资料、发票义务导致付款条件未成就的，甲方对未成就部分不承担逾期付款责任；但甲方不得以此为由无限期拖延已确认、已具备付款条件的款项。
7. 乙方指定收款账户如下：
主收款账户：________  
备用收款账户：________
8. 乙方变更收款账户的，应提前书面通知甲方；未通知导致甲方按原账户付款的，不视为甲方违约。

## 第十一条 安全管理、事故与异常处理

1. 乙方对运输全过程安全负责，包括装货、在途、卸货、交接等环节。
2. 因乙方原因导致货物毁损、灭失、短少、污染、变质的，乙方应按实际直接损失承担赔偿责任。
3. 乙方应确保本项目车辆已购买交强险、车损险、第三者责任险及双方约定的其他保险。
4. 发生交通事故、车辆故障、货损货差、车辆被盗抢、车辆被查封或其他重大异常事件时，乙方应立即采取处置措施，并在约定时限内通知甲方。
5. 异常通知和处置过程，按附件七《异常事件通知与处置流程表》执行。
6. 因乙方未及时通知、未及时处置或未配合证据保全导致损失扩大的，乙方应对扩大部分承担责任。

## 第十二条 执行边界触发、缩量执行与恢复执行

1. 经价格校验或专项复核，项目进入执行边界触发区的，双方应通过附件六《执行边界触发与恢复确认单》固定触发事实和处理意见。
2. 执行边界触发后，应按以下顺序处理：
一是停止按原节奏新增投放；  
二是分类处理在途任务和已承诺任务；  
三是组织价格重谈、运量复核和付款条件复核；  
四是根据复核结果决定缩量执行、暂停执行或恢复执行。
3. 在承压执行区或执行边界触发区内，甲方不得要求乙方无条件持续执行新增任务。
4. 恢复执行前，双方应对价格条件、执行条件、车辆条件和人员条件重新复核确认。

## 第十三条 服务质量与时效要求

1. 乙方应按任务要求准时到场、准时提货、准时送达。
2. 因乙方自身原因造成迟到、延误、漏装、错送的，甲方有权按本协议及附件约定追究责任。
3. 因甲方、收货方、现场条件、政策变化或其他非乙方单方可控原因导致迟延的，不当然认定为乙方违约。
4. 因乙方原因引发客户投诉、平台投诉或重大服务质量事件，并造成甲方直接损失的，乙方应承担相应责任。

## 第十四条 真实性管理与穿透要求

1. 乙方保证本协议项下任务为真实执行，不存在虚假运输、空跑骗补、伪造运单、伪造单据等行为。
2. 乙方保证执行资料、轨迹数据、司机信息、装卸记录真实、完整、可核验。
3. 甲方有权对运输执行情况进行抽查、复核，方式包括现场检查、电话回访、视频核验、轨迹核查和系统数据校验等。
4. 乙方存在虚假执行、虚假资料、数据造假等情形的，甲方有权：
一是拒付对应任务全部运费；  
二是要求乙方返还已支付款项；  
三是要求乙方承担违约责任；  
四是解除本协议；  
五是依法追究其他责任。

## 第十五条 违约责任

1. 甲方违约责任：
一是甲方对已确认、已具备付款条件的款项无正当理由逾期支付的，应承担相应违约责任；  
二是甲方无故取消已确认且乙方已实际准备的任务，造成乙方合理直接损失的，应承担相应赔偿责任。
2. 乙方违约责任：
一是未按约完成任务且无正当理由的，应承担相应违约责任；  
二是造成货损、货差、污染、灭失的，应承担相应赔偿责任；  
三是回传虚假资料、擅自转委托、重大安全违规或重大服务质量问题的，甲方有权解除协议并追责。
3. 责任边界：
一是甲方不承担未确认上游收入情况下的无限垫付责任；  
二是乙方不承担未在本协议中明示传导的无限价格波动风险；  
三是双方违约责任均以明确违约行为和实际直接损失为限。

## 第十六条 协议解除与清算

1. 出现下列情形之一，守约方有权解除本协议：
一是一方发生重大违约，经催告后仍未整改；  
二是一方资质失效或持续不具备履约能力；  
三是一方存在虚假执行、重大安全事故或重大诚信问题；  
四是法律规定的其他可解除情形。
2. 因黄骅港项目总包合同提前终止、专项模型停止适用或不可抗力导致本协议无法继续履行的，双方可协商终止本协议。
3. 协议终止后，双方应在约定期限内完成对账、付款、票据、资料和争议事项清理。
4. 已执行未结算任务，仍按本协议约定完成结算和责任划分。

## 第十七条 保密、通知与送达

1. 双方应对本协议内容及履行过程中知悉的商业秘密、价格信息、客户信息、运营数据承担保密义务。
2. 双方就本协议履行发出的通知、要求和确认，应以书面形式送达，包括电子邮件、系统通知、快递函件等。
3. 电子邮件或系统通知一经发送至本协议确认的地址或账号并可合理证明送达，即视为有效送达。
4. 一方变更联系人、地址、邮箱的，应及时书面通知对方；未通知的，原联系方式送达仍视为有效。

## 第十八条 不可抗力

因不可抗力导致车辆毁损、任务无法执行或协议无法履行的，双方互不承担违约责任，但应及时通知并采取合理减损措施。  
不可抗力持续超过约定期限，双方均有权终止本协议，并按实际已完成业务进行清算。

## 第十九条 争议解决

因本协议引起的或与本协议有关的争议，双方应先协商解决；协商不成的，向甲方所在地有管辖权的人民法院提起诉讼。
