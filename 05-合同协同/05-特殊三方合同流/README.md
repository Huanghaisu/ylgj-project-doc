# 特殊三方合同流

本目录用于承接持车平台、平台公司、合同物流企业在特殊场景下形成的三方合同流文件。

## 当前分层

- `10-正式文本`
  放当前三方主协议正文

- `20-附件汇总`
  放三方协议附件汇总文件

- `30-工作稿`
  放梳理建议、审阅意见等过程材料

- `90-历史拆分结构`
  放旧结构下拆分形成的历史附件、旧模板和旧目录内容

## 当前已归位文件

- `10-正式文本/三方车辆租赁与资产管理协议（调整版）.md`
- `20-附件汇总/三方协议附件.md`
- `30-工作稿/20-工作稿 三方合同 - 梳理建议.md`
- `30-工作稿/20-工作稿 三方合同 - 审阅与归档意见.md`

本目录保留历史结构，但当前新增文件应优先进入上述四个子层。
