### 附件十一：《车辆状态评估与赔偿计算规则》（模板）

#### 一、损耗分类定义

| 分类   | 定义  | 赔偿责任              |
| ---- | --- | ----------------- |
| 正常损耗 |     | 不触发赔偿责任           |
| 异常损耗 |     | 由责任方承担修复费用        |
| 严重损坏 |     | 由责任方承担修复费用+车辆价值损失 |
| 灭失   |     | 由责任方按折旧价值赔偿       |

#### 二、评估方式

1. 损耗性质认定以具有国家认定资质的第三方评估机构出具的书面评估报告为依据。
2. 评估机构由三方共同指定；无法达成一致的，由________所在地________主管部门推荐。
3. 任何一方单方评估结论不得单独作为赔偿计算依据。
#### 三、折旧公式

**车辆折旧评估价 = 车辆原值 × (1 - 已使用年限 ÷ ____) × ____% + 车辆原值 × ____%**
其中：
- 车辆原值：以附件二《车辆信息与权属清单》载明的车辆原值为准
- 已使用年限：自车辆初次登记日起至事故发生之日止，不足一年的按月折算（精确至月）
- 折旧年限：____年
