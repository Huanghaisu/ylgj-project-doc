## 使用规则

1. 计划文件优先服务执行管理，而非仅服务汇报展示。
2. 计划字段应尽量与财务模型、合同条款和上会摘要保持一致。
3. 若后续形成具体项目计划，统一使用 `20-工作稿 项目名 - xxx计划` 命名，成熟后再升级为 `00-基线`。
