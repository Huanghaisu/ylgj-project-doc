# 黄骅港项目五大断点清单

## 一、断点判断结论

确认项目不能按现有口径直接执行。

黄骅港项目的业务场景、运量基础和协同结构仍具备推进条件，但在货主制式合同未锁运价、未稳保最低运价的前提下，现有经营逻辑、合同结构、清分顺序和执行流程已出现五个关键断点，需先完成专项重构后再执行。

## 二、五大断点

### （一）货主合同没有运价锚点

1. 现状：货主制式合同未明确锁定物流运费价格。
2. 问题：项目收入端缺少稳定测算基础。
3. 影响：合同物流企业难以稳定判断经营收益和付款安排。
4. 涉及文件：货主制式合同、财务模型、上会材料收益预测部分。

### （二）风险承接主体变了但文档没变

1. 现状：专项模型拟由承运物流企业承担价格波动收益与风险调节功能。
2. 问题：现有文档尚未将承运物流企业正式定义为专项调节层。
3. 影响：业务真实逻辑与文件逻辑不一致，后续合同与执行口径无法统一。
4. 涉及文件：项目方案、合同映射、分包合同流、上会材料。

### （三）清分逻辑仍停留在旧结构

1. 现状：现有逻辑默认按既有总包、分包和协同结构推进清分。
2. 问题：未正式引入“先保固定成本和硬性费用，再看执行层弹性收益”的专项顺序。
3. 影响：项目无法解释市场波动情景下的资金安排、收益归属和熔断触发。
4. 涉及文件：财务模型、资金清分映射、合同附件、上会材料。

### （四）合同物流企业责权不对等

1. 现状：货主合同未给予稳定价格保障。
2. 问题：若仍按较重责任结构执行，合同物流企业将形成“收入不稳、责任刚性”的失衡状态。
3. 影响：项目在经营上不可承受，在合同上不可接受，在风控上不可闭环。
4. 涉及文件：货主制式合同、合同问题清单、不可接受条款清单、风控说明。

### （五）执行流程缺少价格校验和熔断机制

1. 现状：现有流程已覆盖任务执行、对账回款和月度复盘。
2. 问题：尚未形成执行前价格校验、固定成本覆盖判断和熔断触发流程。
3. 影响：项目即使识别到亏损风险，也缺少正式流程抓手进行缩量、停运和重谈。
4. 涉及文件：操作流程稿、财务模型、上会材料、执行方案。

## 三、处理原则

围绕五大断点执行专项整改。

1. 补运价波动机制，不强行改写整体模型。
2. 补承运物流企业专项定义，不改角色词典主定义。
3. 补专项清分顺序，不改母版资金结构。
4. 补合同物流企业责任收缩边界，不提前在上会材料法律化展开。
5. 补价格校验和熔断流程，恢复项目可执行性。
