# 黄骅港项目资产车刚性成本与运费调节机制设计

## 一、结论

建议将本文件调整为黄骅港项目资产车专项测算说明，不再沿用“只校验资产车刚性成本、按双主体熔断”的旧口径。当前正文统一按执行边界口径理解和引用。

本轮资产车专项判断应统一纳入黄骅港项目现行“运费调节机制”框架，按以下顺序执行：

1. 先确认货主支付物流费用。
2. 先覆盖合同物流企业刚性支出。
3. 再确认承运司机费用、承运管理费用及承运毛利安排。
4. 再判断项目处于正常执行区、承压执行区还是执行边界触发区。

资产车相关成本不再单独构成项目是否继续执行的唯一判断线，而作为合同物流企业刚性支出的核心组成部分，纳入专项清分和风控判断。

## 二、适用范围

本机制仅适用于以下范围：

1. 适用于黄骅港项目当前资产车安排。
2. 适用于合同物流企业租赁模式下的单车及项目汇总测算。
3. 适用于合同物流企业、承运物流企业之间的专项清分和风控判断。
4. 不再单独用于平台公司与合同物流企业双主体刚性付款校验。
5. 不替代项目整体财务模型和月度实际确认结果。

## 三、资产车成本在专项模型中的定位

资产车相关成本属于合同物流企业刚性支出的重要组成部分，应纳入专项风控主口径。

在当前专项模型下，资产车成本不再脱离司机、能源、维保、税费等项目单独判断，也不再按“资产车线是否失守”作为项目停做的唯一标准。

本轮统一按“先保合同物流企业刚性支出”处理，资产车相关成本的判断作用为：

1. 作为合同物流企业执行边界线的重要构成。
2. 作为单车测算和月度运费调节测算的重要输入。
3. 作为判断资产车安排是否具备持续执行条件的基础依据。

## 四、合同物流企业刚性支出口径

合同物流企业刚性支出覆盖要求，按当期实际口径确认，主要包括：

1. 运费垫资利息。
2. 车租垫资利息。
3. 车辆租金，包括牵引车和挂车。
4. 保险费用。
5. 能源费用。
6. 维保费用。
7. 货主支付物流费用对应税费。
8. 其他经双方书面确认、由合同物流企业实际承担且不可向承运侧转嫁的必要支出。

其中，资产车相关成本重点落在以下项目：

1. 车辆租金。
2. 车租垫资利息。
3. 保险费用。
4. 维保费用。
5. 能源费用。

前述项目应与运费垫资利息、税费等共同构成合同物流企业刚性支出覆盖要求，不再单独拆出“资产车执行边界线”。

## 五、专项清分顺序

黄骅港项目资产车专项测算，统一按以下顺序清分：

1. 优先覆盖合同物流企业刚性支出。
2. 再支付承运司机费用。
3. 再支付承运管理费用。
4. 最后确认承运毛利。

该顺序适用于单车测算、月度测算及合同条款口径，不因资产车安排单独改变。

## 六、专项判断逻辑

根据当前财务预测模型中单车租赁模式测算页的采用值，现阶段可直接引用以下边界口径：

1. 当前实际到手运价：`210.00 元/吨趟`。
2. 合同物流企业执行边界线：`149.12 元/吨趟`。
3. 承压执行区边界：`207.71 元/吨趟`。

据此，黄骅港项目资产车专项判断可按以下区间执行：

| 运价区间 | 清分结果 | 风险承担 | 执行动作 |
| --- | --- | --- | --- |
| `> 207.71 元/吨趟` | 正常清分 | 各方按约执行 | 继续执行 |
| `149.12-207.71 元/吨趟` | 先保合同物流企业刚性支出，再压缩承运毛利及执行层收益 | 承运方承担执行层缺口 | 承压执行、加强监测 |
| `< 149.12 元/吨趟` | 无法覆盖合同物流企业刚性支出 | 项目进入执行边界触发区 | 暂停新增、保在途、价格重谈 |

### （一）正常执行区

认定条件：

1. 货主支付物流费用足以覆盖合同物流企业刚性支出。
2. 足以覆盖承运司机费用和承运管理费用。
3. 足以覆盖承运毛利。
4. 折吨运价高于承压执行区边界，即高于 `207.71 元/吨趟`。

管理动作：

1. 按计划组织车辆投放。
2. 按正常节奏组织运输执行和对账付款。
3. 维持常态收益测算口径。

### （二）承压执行区

认定条件：

1. 货主支付物流费用足以覆盖合同物流企业刚性支出。
2. 但不足以完整覆盖承运毛利，或不足以完整覆盖承运司机费用、承运管理费用及承运毛利。
3. 折吨运价处于承压执行区边界与合同物流企业执行边界线之间，即 `149.12-207.71 元/吨趟`。

管理动作：

1. 由承运物流企业承担执行层缺口。
2. 项目原则上继续执行，不当然停止资产车安排。
3. 视运价变化、运量变化和回款情况收紧投放节奏。
4. 强化周度监测和月度复核，及时识别是否进入执行边界触发区。

### （三）执行边界触发区

认定条件：

1. 货主支付物流费用不足以覆盖合同物流企业刚性支出。
2. 或折吨运价低于合同物流企业执行边界线。
3. 现阶段测算口径下，对应折吨运价低于 `149.12 元/吨趟`。

管理动作：

1. 暂停新增投放。
2. 保留在途和已承诺任务。
3. 启动价格重谈、运量复核和付款条件复核。
4. 复核资产车继续执行规模和后续起租安排。

## 七、单车测算建议

资产车专项测算建议统一采用租赁模式、单车口径、`元/吨趟` 单位。

单车测算中，应重点输出以下变量：

1. 货主支付物流费用。
2. 实际到手运价。
3. 合同物流企业刚性支出覆盖要求合计。
4. 合同物流企业执行边界线。
5. 承压执行区边界。
6. 承运毛利。
7. 风险区间判断。
8. 动作结论。

其中，货主支付物流费用为核心变量，税费按货主支付物流费用的适用税率联动计入。

根据当前测算页采用值，建议同步引用以下单车口径数据作为专项说明基线：

1. 单车月运输吨数：`358.40 吨/月`。
2. 货主支付物流费用：`75,264.00 元/月`。
3. 合同物流企业刚性支出覆盖要求合计：`53,443.95 元/月`。
4. 承运司机费用：`20,000.00 元/月`。
5. 承运管理费用：`1,000.00 元/月`。
6. 承运毛利：`820.05 元/月`。

上述数据用于说明当前运价条件下的清分结果和执行边界，不替代后续按月实际确认值。

## 八、预测值与实际值使用原则

黄骅港项目资产车专项测算中的部分数据属于预测性基线数据。为避免预测值与实际值偏差导致判断失真，执行以下原则：

1. 正文锁定规则，不锁定预测数字。
2. 附件锁定签约基线参数，不直接替代月度实际值。
3. 月度确认单作为当期专项判断和动作执行依据。
4. 单车测算结果用于说明口径，不直接替代项目正式结论。
