## 使用规则

1. 提示词应尽量引用统一角色词典与统一口径。
2. 提示词中出现的费率、账期、主体名称应与现有文档一致。
3. 若提示词形成稳定范式，应在本目录集中维护，不在业务文件中重复散落。
