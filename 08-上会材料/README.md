# 上会材料目录说明

## 一、目录定位

本目录用于承接项目立项、决策、汇报及摘要类材料。其内容应以 `02-项目方案` 为叙事底稿，以 `04-财务模型` 为数字底稿，不另行创造新的业务口径。

## 二、建议文件类型

- 项目立项汇报
- 决策汇报材料
- 管理层摘要看板
- 财务测算摘要
- 风控要点摘要
- 合同安排摘要

## 三、表达原则

1. 先结论，后展开。
2. 聚焦必要性、可行性、收益性、风控性。
3. 所有关键数字应能回溯至财务模型。
4. 所有角色称谓应与项目方案一致。

## 四、推荐结构

1. 项目背景与战略意义
2. 项目模式与合作路径
3. 核心参与方与职责安排
4. 关键流程与落地基础
5. 收益测算与资金清分
6. 风控安排与管理建议
7. 需决策事项
