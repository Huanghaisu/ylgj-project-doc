# 黄骅港项目合同物流企业上会材料

本文中，汉江数智科技发展(襄阳)有限公司以下简称“汉江数智”或“合同物流企业”；长江数联物流信息(湖北)股份有限公司（曾用名：湖北供应链物流公共信息服务平台股份有限公司）以下简称“长江数联”或“平台公司”。

本稿采用黄骅港项目专项模型口径。凡涉及价格波动、专项清分、熔断触发和责任收缩的专项安排，均以 `02-项目方案`、`04-财务模型`、`05-合同协同` 下对应 `20-专项 黄骅港项目` 文件为准。

## 一、项目背景

### （一）战略机遇

把握绿色运输替代窗口。

在“双碳”目标持续推进和港口集疏运绿色化升级的背景下，新能源重卡在港口、矿区和大宗物流场景中的应用已由示范导向转向规模化导入。黄骅港作为煤炭下水港和北方重要大宗物流枢纽，货类集中、运量稳定、线路成熟，具备开展新能源重卡规模化运输的现实基础。对合同物流企业而言，黄骅港项目既是承接真实业务需求的重要项目，也是形成新能源履约能力、巩固总包承接能力和提升区域竞争力的关键项目。

### （二）核心货类与运输流向

锁定核心运输场景。

黄骅港项目围绕“山西煤炭入港 + 铝矿出港”的双向运输场景组织实施。上行方向以山西至黄骅港的煤炭运输为主，下行方向以黄骅港至山西方向的铝矿及相关大宗物资运输为主。该场景具备较好的双向配载和返程组织条件，有利于提升车辆利用效率、降低空驶率并形成较为稳定的运输组织基础。

### （三）里程条件与运量基础

明确项目运行底盘。

项目核心线路单程约 `650` 公里，往返约 `1300` 公里，属于典型中长距离重载运输场景。按现有财务模型口径测算，项目年运量目标约 `200` 万吨，月均运量目标约 `16.67` 万吨，预计车辆需求规模约 `500` 台，并按项目推进节奏分阶段投放。上述指标说明项目具备较强的经营体量和标准化组织基础，可支撑合同物流企业围绕总包承接、分包组织和履约管理形成持续经营安排。

### （四）项目定位

确立合同物流企业视角下的项目定位。

黄骅港项目应定位为合同物流企业围绕绿色履约要求承接运输总包业务、组织下游执行资源并形成经营闭环的专项项目。项目重点不在单纯增加车辆投入，而在于依托真实货主需求、稳定运量结构和平台协同能力，完成总包业务承接、执行组织和履约能力升级。

### （五）合作基础

夯实项目推进条件。

项目已具备较好的合作基础。一是黄骅港场景真实，运输需求明确，具备稳定运量入口。二是长江数联已具备车辆组织、调度协同、数据管理和过程支持能力，可为项目提供运力协同支撑。三是持车服务公司及相关主体可为项目提供车辆资源和资产侧保障。四是地方平台公司、物流服务公司等执行主体具备参与基础，可支持项目落地实施。

## 二、业务模式

### （一）业务模式概述

构建“总包承接、协同组织、专项调节、执行闭环”的业务结构。

本项目由汉江数智作为总包承接方、业务组织方和履约管理方，对接货主需求、锁定运量入口并统筹项目执行；由长江数联作为平台协同方，围绕车辆组织、调度协同、数据留痕和过程支持开展配套服务；由持车服务公司提供车辆资产资源；由地方平台公司、物流服务公司和承运物流企业共同完成执行层组织与运输履约。

### （二）合同物流企业核心动作

落实四项核心经营动作。

1. 承接货主或场景方运输总包业务，锁定项目运量入口和经营基础。
2. 组织下游分包和执行资源，统筹线路、时效、班次和履约要求。
3. 协同平台公司完成车辆匹配、调度接入、过程跟踪和数据管理。
4. 统筹运费回款、对账确认和付款安排，形成项目经营闭环。

### （三）专项模型下的业务调整

引入黄骅港专项调节逻辑。

在黄骅港专项模型下，项目在保持原有总包承接与协同组织结构不变的前提下，新增承运物流企业作为执行层价格波动收益与风险调节层。项目执行前需先完成价格校验和可执行性判断；市场运价处于可执行区间时，项目按专项口径继续组织执行；市场运价低于固定成本和硬性费用时，项目启动熔断机制，不再按原规模和原节奏继续投放。

## 三、相关方介绍

### （一）货主及场景方

提供项目运量需求和业务场景。

货主及场景方决定项目是否具备持续稳定的运输需求基础，是项目运量入口和经营起点。围绕货主需求形成稳定线路、稳定货类和稳定运输组织，是合同物流企业承接总包业务的前提。

### （二）合同物流企业

承担总包承接和经营组织职能。

汉江数智负责对接货主需求、承接总包业务、组织下游执行资源、统筹运输计划、推进对账回款并形成项目经营闭环，是项目业务承接和经营管理的核心主体。

### （三）平台公司

承担协同组织和过程支持职能。

长江数联依托既有运力组织、调度协同、数据管理和过程支持能力，为汉江数智承接黄骅港项目提供协同支撑，重点提升车辆组织效率、过程可视化水平和项目履约稳定性。

### （四）持车服务公司

承担车辆供给和资产支撑职能。

持车服务公司围绕项目车辆需求提供新能源重卡资源和资产侧保障，为项目分阶段投放和持续运行提供基础条件。

### （五）地方平台公司

承担区域协同和分包组织职能。

地方平台公司围绕区域执行资源、在地衔接和分包协同开展工作，协助项目完成区域内运输组织与现场衔接。

### （六）物流服务公司

承担现场执行和日常运输组织职能。

物流服务公司根据运输计划完成司机组织、车辆调度、现场作业、运单回传和日常运输管理等具体工作，是项目执行层的重要组成部分。

### （七）承运物流企业

承担执行层价格波动收益与风险调节职能。

在黄骅港专项模型下，承运物流企业除承担相应运输执行职能外，还承担专项约定范围内的价格波动收益与风险调节职责，在可执行区间内承接执行层弹性收益，在运价下行时按专项约定吸收执行层波动，并在进入熔断区间时配合项目执行缩量、暂停或重谈安排。

## 四、操作环节及流程

### （一）协议确认阶段

锁定业务入口和专项适用条件。

1. 开展总包业务确认。由汉江数智对接货主或场景方，确认运量、线路、时效、结算周期和执行要求，形成总包业务确认结论。
2. 开展专项模型适用判断。由汉江数智会同长江数联，结合货主合同条件、市场运价和经营测算，确认是否适用黄骅港专项模型。
3. 开展分包组织方案确认。由汉江数智组织长江数联、地方平台公司、物流服务公司和承运物流企业，明确执行分工、协同接口和专项清分口径。
4. 形成阶段输出。输出总包业务确认结论、专项适用结论和分包组织方案。

### （二）投放准备阶段

完成执行前校验和上线条件确认。

1. 开展价格校验。由汉江数智会同长江数联、承运物流企业校验市场运价、固定成本和硬性费用，形成价格校验结果。
2. 开展固定成本覆盖判断。按专项财务口径判断市场运价是否覆盖固定成本、硬性费用并保留最低安全边际。
3. 开展可执行性判断。根据价格校验结果，确认项目处于可执行区间、缩量执行区间还是熔断区间。
4. 开展车辆投放确认。由汉江数智会同长江数联、持车服务公司确认投放批次、投放数量、线路安排和上线时间。
5. 开展上线准备确认。由汉江数智组织长江数联、地方平台公司和物流服务公司，确认司机、线路、装卸接口、系统接入和单据规则。
6. 形成阶段输出。输出价格校验结果、执行决定、车辆投放计划和上线条件确认单。

### （三）运输执行阶段

形成日常运输闭环。

1. 开展任务下达。由汉江数智根据运输计划向下游执行主体下达运输任务，明确起运地、到达地、货类、班次和执行要求。
2. 开展装货执行。由物流服务公司及相关执行主体组织车辆到场、装货和装车确认，汉江数智同步统筹现场节奏。
3. 开展在途跟踪。由长江数联提供车辆在途状态和异常信息支持，汉江数智统筹处理在途异常，承运物流企业配合执行层调整。
4. 开展卸货确认。由执行主体完成卸货交接和结果回传，汉江数智确认运输结果。
5. 开展返程组织。由汉江数智会同长江数联、承运物流企业结合返程货源和车辆状态组织返程任务。
6. 形成阶段输出。输出运输结果确认单、在途记录、异常处理记录和返程任务安排。

### （四）对账清分阶段

按专项顺序组织资金闭环。

1. 开展运输结果汇总。由汉江数智会同长江数联汇总运单、单据、运输结果和对账基础资料。
2. 开展上游回款推进。由汉江数智推进与货主或场景方的对账和回款确认。
3. 开展专项清分判断。由汉江数智会同长江数联、承运物流企业按专项规则确认固定成本覆盖、硬性费用安排和弹性收益归属。
4. 开展付款安排。由汉江数智根据专项清分结果组织付款安排并形成经营结果沉淀。
5. 形成阶段输出。输出运输结果汇总表、回款确认结果、专项清分结果和付款安排表。

### （五）熔断与恢复阶段

建立专项风险控制抓手。

1. 开展熔断触发判断。市场运价低于固定成本和硬性费用时，由汉江数智会同长江数联、承运物流企业确认进入熔断区间。
2. 开展决策与通知。根据熔断判断结果，决定继续执行、缩量执行、暂停投放或停运重谈，并同步通知各参与方。
3. 开展在运任务复核。对已下达、在途或待执行任务分类处理，防止继续扩大亏损执行。
4. 开展恢复执行判断。市场运价恢复至可执行区间后，由汉江数智会同长江数联、承运物流企业复核恢复条件，并决定是否重新组织投放。
5. 形成阶段输出。输出熔断触发结论、专项决策通知和恢复执行决定。

## 五、收益预测

### （一）收益预测结论

按专项模型重构收益口径。

黄骅港项目在专项模型下，合同物流企业收益以总包业务组织收益、履约管理收益和经营留存为主；承运物流企业在可执行区间内按专项约定承接执行层弹性收益，并同步承担相应波动吸收职责；平台公司围绕协同支持和过程服务形成配套收益。项目不再按“货主价格稳定、项目持续刚性执行”的单一前提测算收益。

### （二）收益形成路径

明确三层收益结构。

1. 形成合同物流企业收益。汉江数智围绕总包承接、业务组织、履约管理、对账回款和经营统筹形成组织收益和管理收益。
2. 形成承运物流企业收益。承运物流企业在可执行区间内，围绕执行层价格波动调节形成专项约定范围内的弹性收益。
3. 形成平台协同收益。长江数联围绕车辆组织、调度协同、数据留痕和过程支持形成协同服务收益。

### （三）专项测算原则

执行四项测算原则。

1. 先测市场运价，再测执行条件。
2. 先保固定成本和硬性费用，再确认后续收益安排。
3. 运价正常波动时，按专项模型保持可执行状态。
4. 运价跌破固定成本和硬性费用时，停止按原节奏继续执行。

### （四）三类情景判断

按三类情景开展专项测算。

1. 运价上行情景。项目具备扩量执行条件，合同物流企业、承运物流企业和平台公司可按专项约定形成相应收益。
2. 运价正常波动情景。项目维持常态执行，按专项规则确认固定成本、硬性费用和弹性收益安排。
3. 运价跌破固定成本和硬性费用情景。项目进入熔断区间，不再按原规模测算持续收益，而按缩量、停运或重谈情景测算专项结果。

## 六、风险控制及相关附件

### （一）风险控制结论

按专项模型重构风险控制结构。

黄骅港项目当前风险控制重点不在扩大通用口径，而在围绕货主合同价格不确定、执行层风险吸收、专项清分顺序和熔断流程建立专项抓手。风险控制坚持“专项隔离、责权对等、价格先判、流程可控、结果可回退”的原则。

### （二）主要风险点

识别五类风险。

1. 识别货主合同未锁运价、未保底价和缺少调价机制风险。
2. 识别合同物流企业在收益未锁定情况下的责权失衡风险。
3. 识别承运物流企业调节层未落地导致的执行波动风险。
4. 识别专项清分顺序不清导致的资金安全风险。
5. 识别未设置价格校验和熔断流程导致的持续亏损执行风险。

### （三）控制措施

落实六项控制措施。

1. 建立黄骅港专项模型，严格与基线、模板隔离。
2. 建立货主制式合同问题清单和不可接受条款清单，前置识别上游合同风险。
3. 建立承运物流企业调节机制合同骨架，落实执行层收益风险安排。
4. 建立专项清分与风险映射，统一资金顺序和收益归属。
5. 建立价格校验、固定成本覆盖判断、熔断触发和恢复执行流程。
6. 建立运价上行、正常波动和跌破阈值三类财务测算口径。
