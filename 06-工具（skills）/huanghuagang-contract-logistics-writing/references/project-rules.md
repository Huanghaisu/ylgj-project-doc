# 黄骅港项目合同物流企业专项写作规则

## 一、章节结构校核

起草时优先校核是否保持以下六章结构：

1. 项目背景
2. 业务模式
3. 相关方介绍
4. 操作环节及流程
5. 收益预测
6. 风险控制及相关附件

如存在小节命名调整，应以不偏离母版主结构为前提。

## 二、主体切换校核

从平台公司版本切换为合同物流企业版本时，应重点完成以下转换：

- 切换主语到合同物流企业。
- 重写项目定位和业务模式中的核心判断。
- 保留平台公司的协同价值，不替代合同物流企业成为主叙事主体。

## 三、禁止表述

在项目背景、业务模式、相关方介绍中，不提前展开以下内容：

- “责任不替代”式条款表达
- “独立结算”式条款表达
- “背靠背”式条款表达
- “镜像付款”式条款表达

如确需涉及，应放入风险控制或合同协同文件，不前置到业务叙事章节。

## 四、收益预测写法

收益预测应围绕专项模型展开，但保持上会材料口径，不写成合同条款说明。

优先交代：

1. 收益来源
2. 收益形成条件
3. 关键测算口径
4. 市场波动下的边界条件

不得把专项模型写成全项目通用规则。

## 五、风险控制写法

风险控制应与专项模型保持一致，并重点覆盖：

- 运价波动风险
- 清分节奏风险
- 履约组织风险
- 运营协同风险

写作时应明确：

- 哪类风险由合同物流企业重点管理
- 哪类风险通过专项流程和专项机制控制
- 哪类风险通过合同文件和专项映射约束
