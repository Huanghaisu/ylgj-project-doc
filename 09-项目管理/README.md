# 项目管理总览

本目录用于承接本项目的管理性文件，不直接承接业务方案、合同正文或财务模型，而是用于保证整个多文档体系的一致性、可维护性与可协同性。

建议长期保留以下文件：

- `README.md`
  说明本目录用途与管理边界。
- `TODO.md`
  记录当前阶段的任务分解、推进顺序与协同关系。
- `文档体系总览.md`
  记录整个仓库的文档结构、用途及彼此映射关系。
- `版本日志.md`
  记录关键结构调整与模板升级历史。

当前项目的管理原则如下：

1. 统一词典优先于扩写文件。
2. 平台公司优先于合同物流企业。
3. 管理台账优先于正式展示版本。
4. 财务模型与合同清分口径必须同步维护。
5. 角色定义优先以 `02-项目方案` 为准，再反向约束 `01-业务方案` 的抽象表述。
