# 项目管理总览

本目录用于承接本项目的管理性文件，不直接承接业务方案、合同正文或财务模型，而是用于保证整个多文档体系的一致性、可维护性与可协同性。

## 当前基线

- `README.md`
  作为本目录入口说明。
- `00-基线 项目管理 - 任务清单.md`
  记录当前阶段的任务分解、推进顺序与协同关系。
- `00-基线 仓库 - 文档体系总览.md`
  记录整个仓库的文档结构、用途及彼此映射关系。
- `00-基线 仓库 - 文档体系设计.md`
  记录整体文档体系设计原则。
- `00-基线 平台公司 - 主叙事骨架.md`
  记录平台公司相关主叙事口径。
- `00-基线 项目管理 - 多文件命名与结构规范.md`
  记录当前仓库命名规则。

## 当前归档

- `99-归档 项目管理 - 旧任务清单.md`
  历史任务清单，仅作追溯参考。

当前仓库命名规则统一如下：

- `00-基线`
  当前正式主文件、执行口径文件。
- `10-模板`
  可复用母版、模板、骨架。
- `20-工作稿`
  初稿、讨论稿、专题推进稿。
- `99-归档`
  历史版本、被替代版本、旧方案。

建议以 `00-基线 项目管理 - 多文件命名与结构规范.md` 作为后续新增文件和整理存量文件的统一依据。

当前项目的管理原则如下：

1. 统一词典优先于扩写文件。
2. 平台公司优先于合同物流企业。
3. 管理台账优先于正式展示版本。
4. 财务模型与合同清分口径必须同步维护。
5. 角色定义优先以 `02-项目方案` 为准，再反向约束 `01-业务方案` 的抽象表述。
