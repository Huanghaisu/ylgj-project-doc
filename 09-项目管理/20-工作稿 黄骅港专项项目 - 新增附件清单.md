# 黄骅港专项项目新增附件清单

## 一、清单结论

黄骅港专项项目现有附件基础主要集中在三方合同流，双边合同流附件明显不足。  
本轮新增附件应围绕价格校验、专项清分、执行边界处置恢复、车辆交付、结算对账、执行留痕六个方面补齐。

| 序号 | 附件名称 | 归属合同流 | 主要用途 | 优先级 |

## 三、按合同流建议新增附件

### （一）01-物流总包合同流

1. `价格确认单`
2. `运价调整确认单`
3. `缩量执行/暂停投放/重谈通知单`
4. `运输服务清单`
5. `结算与对账确认单`

新增目的：补齐总包合同侧价格锚点、调价留痕和执行调整程序。

### （二）02-物流分包合同流

1. `承运价格校验表`
2. `固定成本与硬性费用确认表`
3. `专项清分结果确认单`
4. `执行边界触发与恢复确认单`
5. `运输任务执行计划表`
6. `安全管理责任书`

新增目的：补齐承运调节机制、专项清分和执行边界处置恢复的正式抓手。

### （三）03-资产委托合同流

1. `资产委托范围确认书`
2. `车辆交付与移交确认单`
3. `车辆验收标准表`
4. `保险投保与续保责任确认书`
5. `车辆资料接收清单`

新增目的：补齐权属、交付、保险、资料移交和风险转移留痕。

### （四）04-车辆租赁合同流

1. `月度租金与服务结算单`
2. `付款计划与账户信息确认书`
3. `季度对账确认函`
4. `车辆状态评估与赔偿计算规则`

新增目的：补齐租赁关系下的独立结算、独立付款和周期对账抓手。

### （五）05-特殊三方合同流

1. `上线条件确认单`
2. `异常事件通知与处置流程表`
3. `在运任务分类处置清单`
4. `数据采集、监控与授权确认书`
5. `专项决策通知单`

新增目的：补齐三方协同、异常处理、执行边界决策和过程管理留痕。

## 四、与现有附件的复用关系

| 附件类别 | 现有基础 | 处理方式 |
| --- | --- | --- |
| 车辆交付、资料、保险类 | 三方历史拆分结构中已有模板 | 优先复用并按专项口径修订 |
| 数据监控、异常处置类 | 三方历史拆分结构中已有模板 | 优先复用并补专项流程字段 |
| 结算与对账类 | 三方历史拆分结构中已有模板 | 拆分后分别转入车辆租赁流或分包流使用 |
| 价格校验、执行边界恢复类 | 现有目录中缺正式附件 | 需新增起草 |
| 总包调价与执行调整类 | 现有目录中缺正式附件 | 需新增起草 |

## 五、优先新增顺序

1. 先新增价格校验、清分、执行边界类附件。
2. 先新增总包调价和执行调整类附件。
3. 先新增资产交付、租赁结算类附件。
4. 后整合三方协同和过程管理类附件。
