## 使用规则

1. 所有正式数字引用前，应先确认属于预测值、合同值还是实测值。
2. 合同条款涉及费率、账期、清分顺序时，应同步回看本目录基线文件。
3. 若后续新增项目模型工作底稿，统一使用 `20-工作稿 项目名 - 财务分析` 命名。
