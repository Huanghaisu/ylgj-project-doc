# 财务模型说明

## 一、模型定位

本目录用于承接黄骅港新能源重卡项目财务分析模型，核心目标是对项目的收入、成本、清分、相关方收益与敏感性进行结构化测算，并为项目方案、合同安排、上会材料提供量化支撑。

## 二、当前模型分层

### 1. 输入层

- `1-基础参数`

主要承接项目基础假设，包括但不限于：

- 运价
- 单边公里数
- 双边公里数
- 载重
- 日趟数
- 工作日
- 月趟数
- 车队规模
- 购置/租赁比例

### 2. 计算层

- `2-单车成本测算`
- `3-收益测算`
- `3.5-资金清分`

主要完成以下测算：

- 单车购置成本与租赁成本
- 能源、保险、司机、维保、管理等单车月度成本
- 项目月度收入、成本、毛利与毛利率
- 运费、租金、信息服务费、账期收益等清分逻辑

### 3. 输出层

- `4-相关方收益分配`
- `5-资金流向图`
- `6-敏感性分析`
- `持车公司财务分析`

主要输出以下结果：

- 各参与方收入、支出与净收益
- 主要资金流向及路径可视化
- 关键参数变化对利润的影响
- 持车主体投资收益、ROI、IRR 等指标

## 三、后续优化方向

### 1. 数据口径分层

建议后续将每项关键参数区分为：

- 预测值
- 合同值
- 实测值

原则上不直接破坏现有预测模型，而是在输入层增加数据状态与来源字段。

### 2. 映射关系补齐

建议补齐以下映射：

- 业务计划字段 -> 财务模型输入参数
- 合同条款 -> 清分逻辑参数
- 上会摘要指标 -> 模型输出指标

### 3. 模型使用规则

- 关键数字进入正式汇报前，应标注所属口径。
- 合同条款涉及金额、费率、账期时，应同步复核财务模型。
- 若清分逻辑调整，应优先复核 `3.5-资金清分` 与 `4-相关方收益分配`。
