# 京山市运力管家业务汇报材料（正式上会版）

## 一、汇报建议主口径

建议市委、市政府从服务全省绿色低碳交通运输体系建设、服务京山产业转型升级、服务地方国资平台市场化转型三个维度，统筹把握运力管家项目。

省级平台即长江数联，已围绕绿色低碳交通运输体系进行了系统设计和整体规划，并已形成一批可落地、可统计、可示范的应用场景。京山如能依托本地矿产资源和建材运输场景率先切入，由地方平台公司以持车平台方式参与，有条件在全省率先形成“省级平台能力下沉、地方平台资产落地、实体产业场景承接”的示范样板。

建议本次汇报的核心结论概括为一句话：在长江数联统筹规划和能力支撑下，京山完全有条件以矿建材运输场景为突破口，建设区域绿色低碳运输示范项目，带动交通物流降本增效、地方税源培育、平台公司增收和产业协同发展。

## 二、为什么现在要在京山推动这个项目

### （一）这是衔接全省绿色低碳交通运输体系建设的现实抓手

当前，绿色低碳发展已经从理念倡导转向场景落地。对地方而言，关键不在于概念是否先进，而在于能否找到一批真实可跑、可测算、可复制、可考核的应用场景。长江数联作为省级平台，已经完成绿色低碳交通运输体系的整体设计规划，正在推动一批应用场景加快落地，京山具备成为其中重要节点的基础条件。

一是京山具备以矿产、建材等重载运输场景切入的现实基础。

二是该类场景运输需求稳定、线路相对固定、管理边界清晰，适合新能源重卡替代和数字化调度管理。

三是项目一旦跑通，不仅能够形成地方示范效应，还能够纳入省级平台统一统计、统一调度、统一评价体系，形成省地联动的工作闭环。

### （二）这是京山交通物流和产业体系降本增效的重要抓手

运输不是单纯的末端成本，而是产业链组织能力的重要组成部分。对京山而言，推动运力管家项目，不是简单增加一批新能源车辆，而是借助长江数联的平台能力，把分散运力、分散结算、分散管理的传统运输方式，升级为可组织、可管理、可核算、可监管的新型运输体系。

项目落地后，将重点带来以下变化：

1. 让矿产、建材、制造业和园区企业的运输成本更可控。
2. 让重点运输线路的组织效率更高、履约更稳。
3. 让车辆、司机、轨迹、单据、结算等核心要素全部纳入数字化管理。
4. 让交通治理、安全监管、绿色评价和税务合规更有抓手。

### （三）这是地方国资平台公司转型发展的重要抓手

京山地方平台公司以持车平台身份参与，不是单纯承担购车任务，也不是单纯做一个通道主体，而是通过持有车辆资产、参与平台运营、沉淀本地税源、拓展车后和供应链服务，形成新的市场化经营能力。

这类模式的价值在于，既保留了地方平台公司的属地协调和资源整合优势，又通过长江数联输出平台能力、运营标准和风控体系，降低地方平台公司单独进入运输市场的风险和门槛。

## 三、项目总体定位与建设思路

### （一）项目总体定位

京山运力管家项目，建议定位为服务市委、市政府统筹产业发展、绿色交通、国资转型和要素保障的一项综合性平台工程。其本质不是单一运输项目，而是一个“车辆资产平台+运力组织平台+数据治理平台+产业服务平台”的复合型项目。

### （二）总体建设思路

建议坚持“省级平台统筹设计、地方平台持车落地、重点场景优先突破、成熟后再复制放大”的思路推进。

具体可概括为四句话：

1. 由长江数联负责总体规划、平台能力、规则设计和运营赋能。
2. 由京山地方平台公司负责属地承接、车辆持有和资产运营。
3. 由本地矿产、建材及相关重点企业提供真实稳定的运输场景。
4. 由金融、保险、充换电、维保等配套主体共同构建项目支撑体系。

## 四、围绕领导关注事项的重点汇报口径

### （一）关于省地共建和零碳运输走廊建设

建议上会时重点讲清三层逻辑。

第一层逻辑，长江数联已从省级层面设计规划绿色低碳交通运输体系，京山项目不是零散项目，而是省级体系在地方落地的具体场景。

第二层逻辑，所谓零碳运输走廊，现阶段更适合表述为“以新能源重卡替代为基础、以数字化调度和能耗管理为支撑、以可统计可考核为特征的绿色低碳运输走廊”，重点是先把场景跑通、把数据沉淀下来、把示范效果做出来。

第三层逻辑，京山具备以矿建材运输线路先行先试的良好条件，可以先做出一条或几条看得见、算得清、能推广的示范线路，再向更多产业场景复制。

建议京山优先布局以下走廊类型：

1. 矿山至加工厂、建材企业、园区企业的固定重载线路。
2. 骨料、石灰石、砂石等产品向周边消纳市场的中短途线路。
3. 后续与铁路货场、港口集疏运节点相衔接的多式联运线路。

### （二）关于交通部门“两新”推进和物流行业、一二产业降本增效

该项目兼具设备更新和模式创新双重属性。

对交通部门来说，它有利于推动老旧高排放营运车辆更新替代，推动新能源车辆应用推广，推动运输过程数字监管，推动重点源头运输企业规范化管理。

对物流行业来说，它有利于把零散车辆组织成稳定运力池，减少空驶、等待和中间环节，提高履约效率和组织效率。

对一二产业来说，它有利于把运输环节从被动成本转化为主动管理能力，特别是对矿产、建材、农业集采集运、制造业原料配送等场景，降本增效作用更为明显。

建议上会时把降本增效归纳为五个方面：

1. 降低单位能耗成本。
2. 降低运输组织成本。
3. 降低合规管理成本。
4. 提高履约稳定性。
5. 提高产业协同效率。

### （三）关于地方税收和上级政策性补贴

项目对地方最直接的财政意义，在于把部分车辆资产、运力服务、平台服务和相关配套服务尽可能留在本地，从而形成稳定税源和衍生就业。

建议重点讲三点：

1. 京山地方平台公司作为持车平台参与后，车辆资产运营收益、运力服务收益和部分平台服务收益可以在本地沉淀。
2. 充换电、维保、保险、司机服务、场站配套等衍生业务，也会带动本地形成新的税源和就业。
3. 依托长江数联的省级平台背景和示范场景基础，京山项目具备更好的政策申报条件，更容易争取交通、发改、工信、财政等方向的支持。

需要把握的上会口径是：政策补贴可以争取，但不能作为项目成立的前提；税源沉淀和产业带动才是地方真正长期受益的关键。

### （四）关于平台公司的收益、项目模式构建思路以及风控手段

京山地方平台公司收益，不建议讲成单一租赁收益或单一通道收益，而应当讲成“资产收益、运营收益、平台收益、车后收益、协同收益”五类收益共同构成。

具体来看：

1. 资产收益，主要来自车辆资产持有和运营。
2. 运营收益，主要来自运力组织、计划管理、履约管理等。
3. 平台收益，主要来自调度、清分、数据管理和平台服务。
4. 车后收益，主要来自保险、维修、轮胎、补能等增值服务。
5. 协同收益，主要来自后续延伸出的供应链和产业服务。

项目模式建议明确为“长江数联统筹赋能+京山地方平台公司持车承接+场景企业锁定货源+配套机构协同保障”。

风控方面，建议市委主要领导重点把握八项措施：

1. 先锁定货源，再安排车辆投放。
2. 先选择固定线路，再逐步扩展场景。
3. 先做小规模试点，再决定是否放量。
4. 对核心客户实行账期和信用双管理。
5. 对运费、单据、轨迹、对账、付款实行全过程在线留痕。
6. 对车辆权属、保险、维保、司机资质实行统一监管。
7. 对补能设施和运营线路同步规划。
8. 对资金实行专户管理和闭环清分。

### （五）关于资金问题

资金问题建议从“资金需求、资金来源、资金节奏、资金安全”四个层面回答。

第一，资金需求主要包括车辆资产资金、场站和补能设施资金、平台系统建设资金和运营周转资金。

第二，资金来源建议采用“地方平台公司资本金+融资租赁或银行授信+政策性资金支持+运营现金流滚动”的组合模式。

第三，资金节奏必须和业务节奏匹配，坚持按场景成熟度、按订单落实情况、按试点成效分批投放，不能一开始就大规模重资产铺开。

第四，资金安全必须依托真实货源、真实合同、真实运输数据和真实结算链条来保障，坚决不能把项目做成脱离产业场景的单纯融资项目。

建议上会时把这部分总结为一句话：项目资金可以通过多元化工具解决，但前提始终是场景真实、模式成立、回款可控、风险闭环。

## 五、京山地方平台公司作为持车平台的落地建议

### （一）角色定位

建议将京山地方平台公司明确定位为“持车平台、资产平台、属地协同平台”，负责车辆资产承接、属地资源协调和部分经营收益承接，不直接承担全部专业运营职责。

### （二）首批场景建议

建议以京山本地矿产资源及相关建材运输作为首批核心场景，优先选择以下类型：

1. 石灰石、骨料、砂石等相关运输场景。
2. 矿山到加工厂、加工厂到园区、建材企业到重点工程项目的固定线路。
3. 适合新能源重卡高频往返、补能便利、运输组织标准化的线路。

### （三）这样设计的原因

1. 货源稳定，便于签订中长期运输协议。
2. 线路清晰，便于建立标准化运营模型。
3. 重载运输更容易体现新能源替代的经济性。
4. 容易形成地方层面可观测、可展示、可统计的示范成果。

## 六、建议市委市政府   

1. 支持将京山运力管家项目纳入省地共建和绿色低碳交通运输体系的重要示范场景。
2. 支持地方平台公司依法合规参与持车平台和项目投资运营。
3. 支持统筹本地矿产、建材、园区和重点企业运输需求，尽快形成首批示范线路。
4. 支持项目申报相关政策试点、专项资金和示范工程。
5. 支持补能设施、停车场站、装卸节点等配套资源协同布局。

## 七、上会建议结论

建议市委、市政府原则支持京山运力管家项目进入实质性推进阶段。

从全省看，该项目有利于承接长江数联已设计规划的绿色低碳交通运输体系，在地方形成示范应用场景。

从京山看，该项目有利于依托矿产资源和建材运输场景，推动交通物流降本增效、地方税源培育和产业协同发展。

从国资平台看，该项目有利于推动地方平台公司由传统资产管理向市场化资产运营、运力运营和产业服务转型。

建议按照“先试点、后推广，先场景、后规模，先闭环、后扩张”的原则，尽快启动首批线路论证、主体搭建、资金测算和试点运营准备工作。
